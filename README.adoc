= Codex++ Linux Adapter
:toc:
:toclevels: 2

`Codex++ Linux Adapter` is a source-level Linux adaptation project for `BigPizzaV3/CodexPlusPlus`.
It records and reapplies the patches needed to make Codex++ work with the unofficial Linux Codex Desktop build produced by `ilysenko/codex-desktop-linux`.

This repository is maintained as a fork/adaptation of:

* Codex++ upstream: https://github.com/BigPizzaV3/CodexPlusPlus
* Linux Codex Desktop packaging reference: https://github.com/ilysenko/codex-desktop-linux

License: GPL-3.0-or-later.
See xref:LICENSE[].

== What this repository provides

* An Antora documentation component under `docs/`.
* A structured snippet manifest in `docs/modules/ROOT/pages/snippets.adoc`.
* Patch attachments in `docs/modules/ROOT/attachments/patches/`.
* A bilingual PowerShell manager script: `scripts/Manage-CodexPlusPlusLinux.ps1`.

The manager script can install, update, uninstall, and reapply the Linux adaptation from an original Codex++ source package.

== Expected Linux Codex Desktop layout

By default the script expects:

[source,text]
----
$HOME/opt/codex-desktop-linux/codex-app/start.sh
$HOME/opt/codex-desktop-linux/codex-app/version
----

The default Codex++ adapter install path is:

[source,text]
----
$HOME/opt/codex-desktop-linux/codex-app/.codex-plusplus
----

== Install Linux Codex Desktop first

Follow the `README.md` of https://github.com/ilysenko/codex-desktop-linux before installing this adapter.
The commands below are a practical example; review the upstream README for current platform-specific requirements.

[source,shell,subs="attributes,macros"]
----
# Unofficial Linux Codex Desktop build, from:
# https://github.com/ilysenko/codex-desktop-linux

cd "$HOME/opt"
git clone https://github.com/ilysenko/codex-desktop-linux.git
cd codex-desktop-linux

# Check native build requirements.
make setup-native

# Install missing dependencies reported by setup-native.
# Example on Arch Linux:
sudo pacman -S --needed ydotool

# Arch Linux may provide ydotool as a user service.
systemctl --user daemon-reload
systemctl --user enable --now ydotool.service
sudo usermod -a -G input "$USER"

# Build the native app. The Computer Use UI entry is enabled by CODEX_LINUX_ENABLE_COMPUTER_USE_UI=1.
CODEX_LINUX_FEATURES=conversation-mode,copilot-reasoning-effort,example-feature,open-target-discovery,read-aloud,read-aloud-mcp,remote-control-ui,remote-mobile-control,zed-opener \
CODEX_LINUX_DISABLE_FEATURES= \
PACKAGE_WITH_UPDATER=0 \
CODEX_BOOTSTRAP_NONINTERACTIVE=1 \
CODEX_LINUX_ENABLE_COMPUTER_USE_UI=1 \
make build-app

# Optional user-level launch integration.
ln -s "$(pwd)/codex-app/start.sh" "$HOME/.local/bin/codex-desktop-linux"
ln -s "$(pwd)/codex-app/.codex-linux/codex-desktop.png" "$HOME/.local/share/icons/codex-desktop.png"
cp "contrib/user-local-install/files/.local/share/applications/codex-desktop.desktop" "$HOME/.local/share/applications/codex-desktop-linux.desktop"
sed -i 's/^Exec=.*/Exec=codex-desktop-linux/' "$HOME/.local/share/applications/codex-desktop-linux.desktop"
----

To update the Linux Codex Desktop build, replace the `codex.dmg` used by `ilysenko/codex-desktop-linux`, then rerun its build procedure.

== Install adapted Codex++

Run the manager script with PowerShell:

[source,powershell]
----
pwsh ./scripts/Manage-CodexPlusPlusLinux.ps1 -Action install
----

The script defaults are intentionally conservative:

* Codex Desktop root: `$HOME/opt/codex-desktop-linux`
* Codex++ source: fetch `https://github.com/BigPizzaV3/CodexPlusPlus`
* Codex++ install path: `codex-app/.codex-plusplus`
* Regression test snippets: enabled
* Update check prompt: disabled by default

The script has a configuration block at the top.
It supports shell-style path values such as `$HOME/opt/codex-desktop-linux`, `${HOME}/opt/codex-desktop-linux`, `$env:HOME/opt/codex-desktop-linux`, and `~/opt/codex-desktop-linux`.

== Update adapted Codex++

[source,powershell]
----
pwsh ./scripts/Manage-CodexPlusPlusLinux.ps1 -Action update
----

The update action fetches or copies a fresh upstream source, reapplies enabled snippets, rebuilds, and replaces the installed adapter binaries.

== Uninstall adapted Codex++

[source,powershell]
----
pwsh ./scripts/Manage-CodexPlusPlusLinux.ps1 -Action uninstall
----

By default user scripts are preserved.
Change `$PreserveUserScriptsOnUninstall` in the script configuration block if a full purge is required.

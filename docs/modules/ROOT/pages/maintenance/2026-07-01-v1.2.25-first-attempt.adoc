== Current conclusion

The first upstream-mainline attempt is not release-ready. The maintenance workflow is functioning: latest upstream was fixed to `v1.2.25`, source trees were prepared outside Git, compatibility patch directories were introduced, and incompatible patches were identified before build/install. The next engineering step is to rebase `020`, `050`, `060`, and `900` against `v1.2.25` before running AlmaLinux/GUI validation.

* The requested XFS loop image exists at `$HOME/.local/share/podman-loop-storage/containers-storage.xfs`, but this session cannot mount it because elevated mount operations are unavailable.
* AlmaLinux container install/update/uninstall and GUI validation were therefore not executed in this first attempt.
